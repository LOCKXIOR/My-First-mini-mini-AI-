### How to really use it? 
As you can tell by looking at the .py files, je n'ai pas vraiment fait d'interface où un 
utilisateurs tiers peut entrer des valeurs... On est obligé de directement toucher au code... mais
comme il est 23:18 là... I am a bit tired so...
- On "Homme ou woman" : modifiez juste les valeurs dans la variable "teste_moi" (l'ordre : Taille(cm), Masse(kg))
- Sur "Retard de vol" : change the values in "ped" variable (order : Distance(km), Heure de départ (les '.5' sont considérés comme ..:30), Nb passagers)
